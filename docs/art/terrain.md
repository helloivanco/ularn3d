# Terrain surface family

Procedural surface maps painted at runtime by `src/materials.js`. Nothing is downloaded or
generated by an image model: every map is drawn deterministically on a canvas from the shared
`noise()` hash, so the same build always produces the same pixels. No third-party art, fonts or
licenses are involved.

## Technical frame

| Property | Value |
|----------|-------|
| Engine | three.js 0.186, perspective camera from above, 1 world unit per tile |
| Map size | 512 × 512 texels per tile (`MAP_SIZE`); drawn from one logical 128-unit pattern |
| Display | ~80–100 CSS px per tile at the default zoom, up to ~200 device px at 2× density |
| Color space | sRGB color map; normal and roughness maps derived from its luminance at the same size |
| Sampling | Repeat wrapping, mipmaps, anisotropy 2; roof uses trilinear blending, the rest nearest-mip |
| Lighting | Cave terrain is unlit (`MeshBasicMaterial`), so shading is painted into the color map |
| Tint | Instance colors and `STONE_TINT` multiply the maps per region and per tile |
| Cost | About 50 ms to paint all five maps once at load; ~1.4 MB GPU memory per map with mips |

## Visual system

- **Shape language:** chunky, hand-cut blocks with softened corners and slightly irregular edges.
  Edges are jittered, never wobbly.
- **Value structure:** a dark rim rising to a paler crown on every stone. It reads as a rounded
  block from any side, so floors can turn per tile without the light flipping. Wall courses add
  a top-down key (lighter top edge, darker base).
- **Palette roles:** neutral, slightly warm greys for stone; a narrow hue range on floors, where
  the per-tile instance tint carries the variety. Moss lives in joints, never as blotches over the
  stone. Grass is a muted meadow green with pale tips. Slate is cool grey and wood is a weathered tan.
- **Detail density:** cracks on about a third of stones, faint sediment bands, mid-scale flecks
  and per-texel grain. Large detail reads at game scale and fine detail rewards zooming in.
- **Brightness:** each map's mean stays within a few levels of the 1.3.82 maps (stone ≈ 117,
  grass ≈ 114, wood ≈ 126, roof ≈ 114 on 0–255), so scene exposure and tints are unchanged.

## Manifest

| Kind | Used by | Layout | Seam rule |
|------|---------|--------|-----------|
| `flags` | Floor tiles (cave, volcano, town paths, title paths) | Nine-stone ashlar on a 4 × 4 grid with offset lines | Every map edge is a joint; tiles turn/mirror per instance |
| `stone` | Wall and cap courses, building masonry, the volcano's `volcanic` | Four running-bond courses with uneven block lengths | Shapes repeat across the wrap; head joints ≥ 10 units apart between rows |
| `grass` | Town lawn tiles, the meadow outside the town walls, the title field | Soft patches, tuft shadows, ~3000 blades, a few flowers and pebbles | Wrap-aware drawing; tiles turn/mirror per instance |
| `roof` | Gable slabs (turned a quarter per side) and conical tower roofs | Eight slate courses, lips toward the canvas bottom (eave) | Rows sum exactly to the map width; bottom row's lip repeats at the top |
| `basalt` | Volcano floor tiles | Nine cooled slabs (periodic Voronoi), gas pocks, about a third of the joints glowing | Every map edge is a joint and only slab-to-slab joints glow, so turned tiles stay seamless |
| `wood` | Posts, beams, doors and shutters | Four planks with grain, knots, butt joints and nails | Grain waves repeat a whole number of times per map |

Floors use `tileScatter()`: the vertex shader hashes each instance's tile position into one of
eight orientations (four turns × optional mirror) and applies it to the color, normal and
roughness UVs, and to the emissive UVs where a surface has them. Walls and caps are not
scattered, so their courses stay level.

Cinematic caves light the stone for real: floors, walls and caps use the lit PBR surfaces with
these color, relief and roughness maps, under the lantern and torch lights (`src/cave-light.js`).
Volcano basalt adds `glowMap("basalt")` as an emissive map, taken from the molten cores of its
fissures, so lava glows where no light reaches. Auto and Balanced caves keep flat terrain.

Large slabs repeat the map once per tile through `placedTexture()` instead of stretching one map
across them: the 67 × 17 town ground and the 21 × 16 title-screen field. Gable roof slabs use a
quarter turn so courses run along the ridge with their lips toward the eave.
